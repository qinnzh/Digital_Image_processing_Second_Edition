# 像素之间｜数字图像处理期末速通课

一个可以**离线双击浏览**、也可以直接部署到 **GitHub Pages** 的静态教学网站。

## 内容

- 第1章 绪论
- 第2章 数字图像基础
- 第3章 空间域增强（灰度变换、直方图均衡、均值/中值、拉普拉斯、梯度）

- 第6章 形态学（腐蚀、膨胀、开闭操作等）

**交互实验（5个）：**直方图均衡化（含图表、累计概率和映射表）、γ变换曲线、3×3均值/中值/拉普拉斯计算器、频谱对称陷波示意、7×7形态学像素编辑器。

## 本地预览

1. 解压下载的压缩包，打开 `my-page` 文件夹。
2. **双击 `index.html`**，推荐使用近期版本的 Chrome、Edge、Firefox 或 Safari。
3. 检查导航、图片、公式和交互模块。
4. 也可以在 VS Code 安装 *Live Server*，用它打开项目，但**并非必须**。

所有资源均使用相对路径：`style.css`、`script.js`、`images/*.svg`，没有 CDN、第三方字体、前端框架或后台服务。当前示意图、公式与交互均可离线显示。数学公式采用浏览器可以直接呈现的 HTML/Unicode、上标、下标和 SVG，并没有依赖特殊数学绘图库。

## GitHub Pages 部署

1. 登录 GitHub，新建公开仓库（例如 `digital-image-processing`）。
2. 上传 `my-page` **内部**的所有文件和 `images` 目录，确保仓库根目录里直接能看到 `index.html`。
   - 请不要把整个 `my-page/` 再嵌套到仓库的下一层，否则下面选择根目录部署时会找不到 `index.html`。
3. 提交（Commit changes）。
4. 进入仓库 `Settings` → `Pages`。
5. `Build and deployment` → `Source: Deploy from a branch` → `Branch: main` → `Folder: / (root)` → `Save`。
6. GitHub Pages 部署成功后，访问：
   `https://你的GitHub用户名.github.io/你的仓库名/`

注意：仓库如果是 `你的用户名.github.io`，网站地址通常是 `https://你的用户名.github.io/`，没有额外仓库名路径。GitHub实际按钮位置可能随界面更新。

## 常见问题

- **只有文字、没有样式？** 检查 `index.html` 和 `style.css` 是否处于同一文件夹。
- **插画不显示？** 检查 `images/` 是否完整上传；Linux/GitHub 大小写敏感。
- **按钮没有反应？** 检查 `script.js` 是否在同级目录；浏览器开发者工具 Console 中是否有报错。
- **刚上传 GitHub 访问404？** 核对 Pages 分支、根目录和仓库根层的 `index.html`，再查看仓库 Actions/Pages 发布状态。
- **学习进度与笔记换电脑后不在？** 这些内容以浏览器本地存储记录，不会同步到云端。
- **想分享到微信或朋友圈？** 直接转发 GitHub Pages 网站链接即可，无须访问者登录 GitHub（公开仓库）。
